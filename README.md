# My Quizlet

Ứng dụng học từ vựng/flashcard cá nhân, lấy trải nghiệm học linh hoạt kiểu Quizlet nhưng bổ sung cơ chế Spaced Repetition (SRS) và lịch sử học đầy đủ mà không buộc người dùng phải reset deck để học lại.

## Mục tiêu

- Học lại bất kỳ deck hoặc tập card nào bất cứ lúc nào mà không phá tiến độ SRS.
- Hỗ trợ flashcard, review theo lịch, quiz và học tự do.
- Phù hợp trước hết với việc học từ vựng tiếng Nhật/JLPT, nhưng mô hình dữ liệu không khóa vào riêng tiếng Nhật.
- Import dữ liệu dễ dàng để có thể dùng trực tiếp các bộ từ vựng được chuẩn bị bên ngoài.

## Tech stack

- Frontend: React + TypeScript
- Backend: ASP.NET Core Web API (.NET)
- Database: PostgreSQL
- Container: Docker / Docker Compose
- UI: Fluent UI
